# KeyVault
ARM Template for deploying lab for AppService Config Key Vault Lab #2

[![Deploy To Azure](https://aka.ms/deploytoazurebutton)](https://portal.azure.com/#create/Microsoft.Template/uri/https%3A%2F%2Fraw.githubusercontent.com%2Famyluums%2FKeyvalult%2Fmain%2Fazuredeploy.json)


## This arm deployment will:

1. Create an App Service with App Service Plan
2. Create an Azure Key Vault
3. Create a virtual network
4. Create a VM on the virtual network
